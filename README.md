Projeto da cadeira de álgebra linear.

O código tem como objetivo calcular a quantidade de operações necessárias em cada lado da igualdade da distributiva de matrizes A(B+C) = AB + AC e ver qual lado é mais eficiente computacionalmente.
Além disso o código gera uma visualização dos vetores gerados.
